---
title: Contribuindo
description: Como contribuir com o InnovUI.
---

O InnovUI é open source. O guia completo — setup local, fluxo de PR, padrão de commits e como adicionar um componente novo — está no [CONTRIBUTING.md](https://github.com/innovtech-developers/innovui/blob/main/CONTRIBUTING.md) do repositório.

Resumo rápido:

```sh
git clone https://github.com/innovtech-developers/innovui.git
cd innovui
pnpm install
pnpm dev
```

Dúvidas ou sugestões: [abra uma issue](https://github.com/innovtech-developers/innovui/issues).
