Área para escolher arquivos clicando ou arrastando-os para dentro. O Upload **só captura os arquivos**: listar o que foi escolhido, validar tamanho e enviar ao servidor ficam com você, como na demo abaixo, que usa uma [List](/react/components/list/).

<UploadDemo client:load />

```tsx
import { Upload } from '@innovui/react'

<Upload
  multiple
  accept=".pdf,image/*"
  description="PDF ou imagem, até 5 MB"
  aria-label="Anexos"
  onFilesChange={(files) => setFiles((current) => [...current, ...files])}
/>
```

`onFilesChange` recebe sempre os arquivos **que acabaram de ser escolhidos**, não a soma com os anteriores. Para acumular, junte no seu estado, como acima.

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `onFilesChange` | `(files: File[]) => void` | — | **Obrigatória.** Chamada com os arquivos escolhidos. |
| `title` | `ReactNode` | "Arraste arquivos aqui ou clique para escolher" | Texto principal. |
| `description` | `ReactNode` | — | Texto de apoio (formatos e tamanho aceitos). |
| `accept` | `string` | — | Tipos aceitos: `.pdf`, `image/*`, `image/png`, separados por vírgula. |
| `multiple` | `boolean` | `false` | Aceita vários arquivos. Sem ele, só o primeiro de uma seleção entra. |
| `error` | `boolean` | `false` | Borda vermelha e `aria-invalid`. |
| `disabled` | `boolean` | `false` | Bloqueia clicar e arrastar. |
| `name` | `string` | — | Nome do campo de arquivo, se for usado num `<form>` nativo. |

Aceita também as props nativas de `<input type="file">`.

## Acessibilidade

- O seletor de arquivos é um `<input type="file">` de verdade, escondido só visualmente: recebe foco com `Tab` e abre com `Enter` ou `Espaço`, e a área inteira é o rótulo dele.
- Arrastar é um atalho para quem usa mouse; o clique e o teclado fazem o mesmo.
- O `accept` também filtra o que é **arrastado** (o navegador não faz isso): arquivos de outro tipo são ignorados. Ainda assim, valide no servidor.
- Avise o resultado fora da área, ex.: a lista de arquivos ou uma mensagem de erro ligada com `aria-describedby`.

### Quando não usar

Arquivos grandes que precisam de progresso e retomada (o Upload não envia nada) ou quando basta um botão simples para anexar.
