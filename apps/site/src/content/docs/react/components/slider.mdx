Escolhe um número dentro de uma faixa arrastando a alça ou usando as setas. Serve quando o valor exato importa menos do que a posição na faixa, como volume, brilho ou faixa de preço.

<SliderDemo client:load />

```tsx
import { Slider } from '@innovui/react'

const [value, setValue] = useState([40])

<Slider aria-label="Volume" value={value} onValueChange={setValue} max={100} />
```

O valor é **sempre um array**: `[40]` para um valor, `[20, 80]` para um intervalo. O Slider não mostra o número escolhido; escreva-o ao lado, como na demo.

## Intervalo

Com dois valores, o Slider tem duas alças e preenche a faixa entre elas. Dê um nome a cada alça com `thumbLabels`.

<SliderRangeDemo client:load />

```tsx
<Slider
  aria-label="Preço"
  thumbLabels={['Preço mínimo', 'Preço máximo']}
  value={range}
  onValueChange={setRange}
  min={0}
  max={1000}
  step={10}
/>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `value` / `defaultValue` | `number[]` | `[min]` | Valores (controlado ou inicial). Um por alça. |
| `onValueChange` | `(value: number[]) => void` | — | Chamado enquanto a alça se move. |
| `onValueCommit` | `(value: number[]) => void` | — | Chamado ao soltar a alça; use para buscar dados só no fim. |
| `min` / `max` | `number` | `0` / `100` | Limites da faixa. |
| `step` | `number` | `1` | Passo entre valores. |
| `minStepsBetweenThumbs` | `number` | `0` | No intervalo, distância mínima entre as alças. |
| `disabled` | `boolean` | `false` | Bloqueia o uso. |
| `name` | `string` | — | Nome do campo em formulários. |
| `aria-label` | `string` | — | **Necessário.** Nome acessível; com várias alças ganha o número. |
| `thumbLabels` | `string[]` | — | Nome acessível de cada alça, no lugar do `aria-label` numerado. |

## Acessibilidade

- Cada alça é um `role="slider"` com `aria-valuenow`, `aria-valuemin` e `aria-valuemax`.
- `←` `→` (e `↑` `↓`) mudam um passo, `Page Up`/`Page Down` mudam dez passos, `Home` e `End` vão aos extremos.
- Sem `aria-label`, a alça não tem nome: sempre passe um.
- Mostre o valor escolhido em texto. A posição da alça sozinha não diz o número exato.

### Quando não usar

Valores que precisam ser exatos e digitados (use [Input](/react/components/input/)) e escolha entre poucas opções discretas ([Radio](/react/components/radio/) ou [SegmentedControl](/react/components/segmented-control/)).
