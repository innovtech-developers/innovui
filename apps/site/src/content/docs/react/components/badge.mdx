Indicador compacto de **status**, com cor semântica embutida e sem interação. Para categorizar ou rotular conteúdo, use a [Tag](/react/components/tag/).

<BadgeDemo client:load />

```tsx
import { Badge } from '@innovui/react'

<Badge status="success">Pago</Badge>
<Badge status="error">Recusado</Badge>
<Badge status="warning">Atenção</Badge>
<Badge status="info">Novo</Badge>
<Badge status="neutral">Rascunho</Badge>
<Badge status="pending">Pendente</Badge>
```

## Com indicador

<BadgeDotDemo client:load />

```tsx
<Badge status="success" dot>Ativo</Badge>
```

O indicador usa a mesma cor do texto e é decorativo (`aria-hidden`).

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `status` | `'success' \| 'error' \| 'warning' \| 'info' \| 'neutral' \| 'pending'` | `'neutral'` | Cor semântica do status. |
| `dot` | `boolean` | `false` | Mostra o indicador circular antes do texto. |
| `children` | `ReactNode` | — | O texto do badge. |
| `className` | `string` | — | Mesclado com as classes internas via `tailwind-merge`. |

Aceita também as props nativas de `<span>`.

## Acessibilidade

- A cor nunca é o único sinal: o texto do badge deve dizer o status ("Pago", "Recusado"), não só mudar de cor.
- Contraste entre texto e fundo conforme os tokens `status/*` do design system.
- O Badge não é interativo e não recebe foco.

### Quando usar

Status de pedido, severidade, estado de uma conta ou de um item numa lista.

### Quando não usar

Categorias ou filtros (use [Tag](/react/components/tag/)) e contadores de notificação.
