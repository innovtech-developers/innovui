Leva a outra página ou seção. A cor da marca e o sublinhado permanente deixam claro que o texto é clicável.

<LinkDemo client:load />

```tsx
import { Link } from '@innovui/react'

<Link href="/instalacao">instalação</Link>

// com o link do seu roteador (Next.js, React Router...)
<Link asChild>
  <NextLink href="/instalacao">instalação</NextLink>
</Link>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `asChild` | `boolean` | `false` | Aplica o estilo ao filho (ex.: o `<Link>` do roteador) em vez de renderizar um `<a>`. |
| `className` | `string` | — | Mesclado via `tailwind-merge`. |

Aceita também as props nativas de `<a>`.

## Acessibilidade

- O sublinhado é permanente: só a cor não distingue o link do texto ao redor (WCAG 1.4.1).
- Foco visível por anel de 2px, e o link é um `<a href>` de verdade, alcançável por Tab e ativado por Enter.
- Em links que abrem em outra aba (`target="_blank"`), use `rel="noreferrer"` e avise no texto.

### Quando não usar

Para uma **ação** (enviar, abrir um modal), use [Button](/react/components/button/). Link navega; Button age.
