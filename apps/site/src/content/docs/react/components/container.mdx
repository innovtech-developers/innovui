import { ContainerDemo } from '../../../../components/demos/LayoutDemos'

Limita a largura do conteúdo e o centraliza na tela, com margem lateral de 16px no mobile e 24px a partir do tablet. Use no topo de cada página ou seção para o texto não esticar em telas largas.

<ContainerDemo client:load />

```tsx
import { Container } from '@innovui/react'

<Container>
  <h1>Pedidos</h1>
</Container>
```

| `size` | Largura máxima |
|---|---|
| `sm` | 640px |
| `md` | 960px |
| `lg` (padrão) | 1200px |
| `xl` | 1440px (o breakpoint de desktop do DS) |

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | `'lg'` | Largura máxima. |
| `className` | `string` | — | Mesclado via `tailwind-merge`; use para trocar a largura (ex.: `iu:max-w-prose`). |

Aceita também as props nativas de `<div>`.

## Acessibilidade

Só layout, sem papel ARIA. Use os elementos semânticos dentro dele (`<main>`, `<section>`, `<h1>`).
