Rótulo para **categorizar** conteúdo ou mostrar filtros ativos, em cor neutra. Para status, use o [Badge](/react/components/badge/).

<TagDemo client:load />

```tsx
import { Tag } from '@innovui/react'

<Tag>Design</Tag>
<Tag variant="outline">Código</Tag>
```

## Removível

<TagDismissDemo client:load />

```tsx
<Tag onDismiss={() => remove(tag)} dismissLabel={`Remover ${tag}`}>
  {tag}
</Tag>
```

O botão de remoção (×) aparece quando `onDismiss` é passado. Use `dismissLabel` para dizer **o que** será removido; o padrão é "Remover".

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `variant` | `'filled' \| 'outline'` | `'filled'` | Fundo sólido ou apenas borda. |
| `onDismiss` | `() => void` | — | Mostra o botão de remoção e o chama ao clicar. |
| `dismissLabel` | `string` | `'Remover'` | Nome acessível do botão de remoção. |
| `children` | `ReactNode` | — | O texto da tag. |
| `className` | `string` | — | Mesclado com as classes internas via `tailwind-merge`. |

Aceita também as props nativas de `<span>`.

## Acessibilidade

- O botão de remoção é um `<button>` real, com foco visível e acionável por teclado.
- Em listas de tags removíveis, use um `dismissLabel` específico ("Remover React") para que cada botão tenha um nome distinto.

### Quando usar

Tags de artigo, filtros ativos, categorias.

### Quando não usar

Status com cor semântica (use [Badge](/react/components/badge/)).
