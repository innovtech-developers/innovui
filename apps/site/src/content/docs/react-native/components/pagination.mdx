Navegação entre as **páginas** de uma lista ou [tabela](/react-native/components/table/), com botões de anterior e próxima, a primeira, a última, a atual e as vizinhas. O componente é controlado: você guarda o estado de `page`.

```tsx
import { Pagination } from '@innovui/react-native'

const [page, setPage] = useState(1)

<Pagination page={page} pageCount={20} onPageChange={setPage} />
```

A barra mantém sempre o mesmo número de itens, com reticências no que sobra, para não pular de largura ao trocar de página.

## Poucas páginas

Quando `pageCount` é menor ou igual a `siblingCount * 2 + 5` (7 com o padrão), todas as páginas aparecem, sem reticências.

```tsx
<Pagination page={page} pageCount={5} onPageChange={setPage} />
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `page` | `number` | n/a | **Obrigatória.** Página atual, começando em 1. |
| `pageCount` | `number` | n/a | **Obrigatória.** Total de páginas. |
| `onPageChange` | `(page: number) => void` | n/a | **Obrigatória.** Chamado com a página escolhida. |
| `siblingCount` | `number` | `1` | Páginas vizinhas da atual mostradas de cada lado. |
| `previousLabel` | `string` | `'Página anterior'` | Nome acessível do botão de anterior. |
| `nextLabel` | `string` | `'Próxima página'` | Nome acessível do botão de próxima. |
| `accessibilityLabel` | `string` | `'Paginação'` | Nome acessível da barra. |
| `className` | `string` | n/a | Mesclado com as classes internas via `tailwind-merge`. |

Aceita as demais props de `View`.

## Particularidades

- A página atual é anunciada como `selected`.
- O botão de anterior é desabilitado na página 1, e o de próxima na última.

## Acessibilidade

- A barra é uma `View` com `accessibilityLabel`, porque o RN não tem role `navigation`.
- Cada página é um `Pressable` com `accessibilityRole="button"`, `accessibilityLabel="Página N"` e `accessibilityState={{ selected }}` para a atual.
- Os botões de anterior e próxima têm `accessibilityLabel` e `disabled` em `accessibilityState`.
- As reticências ficam ocultas para leitores de tela.

### Quando usar

Conjuntos grandes de dados mostrados por páginas, geralmente junto de uma [Table](/react-native/components/table/).

### Quando não usar

Listas longas com rolagem contínua (use `FlatList` com carregamento incremental) e fluxos em etapas ([Stepper](/react-native/components/stepper/)).
