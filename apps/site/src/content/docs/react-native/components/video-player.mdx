title: VideoPlayer
description: Controles de vídeo (play central, posição, tempo e tela cheia) sobre o seu vídeo (expo-video).
---

Desenha os controles de um vídeo sobre a superfície que você colocar dentro dele, no estilo dos players de celular: play/pause grande no centro e, embaixo, o tempo com a tela cheia à direita e a barra de posição.

O React Native não tem player de vídeo embutido, então o `VideoPlayer` é só a **casca**: ele recebe o vídeo como `children`, desenha o estado que você passa e avisa o que o usuário fez. Quem toca é o seu player; com o Expo, o [`expo-video`](https://docs.expo.dev/versions/latest/sdk/video/).

```tsx
import { VideoPlayer } from '@innovui/react-native'
import { useEvent } from 'expo'
import { useVideoPlayer, VideoView } from 'expo-video'
import { useRef, useState } from 'react'

export function VideoDoCliente({ uri }: { uri: string }) {
  const view = useRef<VideoView>(null)
  const player = useVideoPlayer(uri, (p) => {
    p.timeUpdateEventInterval = 0.25
  })
  const { isPlaying } = useEvent(player, 'playingChange', { isPlaying: player.playing })
  const { currentTime } = useEvent(player, 'timeUpdate', {
    currentTime: player.currentTime,
    currentLiveTimestamp: null,
    currentOffsetFromLive: null,
    bufferedPosition: player.bufferedPosition,
  })
  const [fullscreen, setFullscreen] = useState(false)

  return (
    <VideoPlayer
      label="Vídeo enviado pelo cliente"
      playing={isPlaying}
      position={currentTime}
      duration={player.duration}
      fullscreen={fullscreen}
      onPlayPause={() => (isPlaying ? player.pause() : player.play())}
      onSeek={(seconds) => {
        player.currentTime = seconds
      }}
      onToggleFullscreen={() => view.current?.enterFullscreen()}
    >
      <VideoView
        ref={view}
        player={player}
        nativeControls={false}
        contentFit="contain"
        style={{ flex: 1 }}
        onFullscreenEnter={() => setFullscreen(true)}
        onFullscreenExit={() => setFullscreen(false)}
      />
    </VideoPlayer>
  )
}
```

Deixe os controles do próprio vídeo desligados (`nativeControls={false}`) para não aparecerem dois conjuntos. Em tela cheia o vídeo sai do `VideoPlayer` e passa para o player do sistema, então o `VideoPlayer` liga o `nativeControls` do `VideoView` sozinho ao entrar (ele precisa estar ligado antes de abrir, senão o iOS mostra a tela cheia sem play, barra e tempo). Para isso, o `VideoView` deve ser o filho direto, com a prop `nativeControls`, e `fullscreen` deve acompanhar `onFullscreenEnter`/`onFullscreenExit`.

## Comportamento

- **Pausado:** os controles ficam sempre visíveis, com um véu escuro por cima do vídeo.
- **Tocando:** os controles somem depois de 2,5 s sem toques (`hideControlsAfter`). **Tocar no vídeo** mostra ou esconde os controles; para pausar, use o botão central. Assim um toque sem querer não pausa o vídeo. Com leitor de tela ligado, os controles não somem.
- **Reproduzir no fim:** volta ao começo antes de tocar (chama `onSeek(0)` e depois `onPlayPause`).
- **Área de toque:** botões de 44px e barra de posição com 32px de altura, com o marcador na posição atual.
- **Volume:** no celular o volume é o dos botões do aparelho, então o player não tem controle de som.
- **Tela cheia:** o botão só aparece se você passar `onToggleFullscreen`.
- **Proporção:** 16:9 na largura disponível; mude com `className` (ex.: `aspect-square`).

## Personalização

As cores vêm de tokens, então não há prop de cor: sobrescreva o token no `global.css` (veja [Tema e modo escuro](/react-native/tema/#customizando-os-tokens)).

| Parte | Token |
|---|---|
| Parte preenchida da barra de posição | `--color-media-accent` |
| Fundo do vídeo e véu dos controles | `--color-media-surface` |
| Ícones, tempo e botões sobre o vídeo | `--color-media-on-surface` |
| Ícone do play central | `--color-interactive-primary` (o círculo é `--color-media-on-surface`) |

```css title="global.css"
@layer theme {
  :root {
    @variant light {
      --color-media-accent: #0ea5e9;
    }
    @variant dark {
      --color-media-accent: #38bdf8;
    }
  }
}
```

`--color-media-accent` é exclusivo da mídia: trocá-lo não afeta outros componentes. Já `--color-interactive-primary` é usado em vários (como os pontos do Carousel). No React Native os tokens valem para o app inteiro.

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `children` | `ReactNode` | — | **Obrigatória.** A superfície do vídeo (ex.: `VideoView`). |
| `playing` | `boolean` | `false` | Tocando agora: mostra pausar e esconde o play central. |
| `position` | `number` | `0` | Posição atual, em segundos. |
| `duration` | `number` | `0` | Duração total, em segundos. |
| `fullscreen` | `boolean` | `false` | Em tela cheia: mostra o ícone de sair. |
| `label` | `string` | `"Vídeo"` | Nome acessível do player. |
| `hideControlsAfter` | `number` | `2500` | Milissegundos sem toques até esconder os controles tocando. |
| `onPlayPause` | `() => void` | — | Toque no botão central de reproduzir/pausar. |
| `onSeek` | `(seconds: number) => void` | — | Toque ou arraste na barra, em segundos. |
| `onToggleFullscreen` | `() => void` | — | Toque no botão de tela cheia (sem ele, o botão não aparece). |
| `className`, `testID`… | props de `View` | — | Vão para o contêiner. |

## Acessibilidade

- O player tem o `label` como nome; os botões têm nome e o estado muda o nome ("Reproduzir"/"Pausar", "Tela cheia"/"Sair da tela cheia").
- A barra é um elemento **ajustável** ("Posição do vídeo") com valor e texto ("2:14 de 5:32"); o leitor de tela avança e volta 5s por vez.
- Controles escondidos ficam fora do alcance do leitor de tela e do toque.
- Ofereça legendas pelo `expo-video` (`player.availableSubtitleTracks`) para o conteúdo falado.
