Mensagem **persistente em largura total**, para o topo da interface: manutenção, anúncios, avisos que valem para a página inteira. Para mensagens dentro de uma seção, use o [Alert](/components/alert/).

<BannerDemo client:load />

```tsx
import { Banner } from '@innovui/react'

<Banner
  status="info"
  action={<Button variant="ghost" size="sm">Saiba mais</Button>}
  onDismiss={() => setOpen(false)}
>
  Manutenção programada hoje às 22h.
</Banner>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `status` | `'success' \| 'error' \| 'warning' \| 'info' \| 'neutral'` | `'info'` | Cor semântica e ícone. |
| `children` | `ReactNode` | — | A mensagem. |
| `showIcon` | `boolean` | `true` | Mostra o ícone do status. |
| `action` | `ReactNode` | — | Ação ao lado da mensagem (ex.: Button `ghost` `sm`). |
| `onDismiss` | `() => void` | — | Mostra o botão de fechar e o chama ao clicar. |
| `dismissLabel` | `string` | `'Fechar'` | Nome acessível do botão de fechar. |
| `className` | `string` | — | Mesclado com as classes internas via `tailwind-merge`. |

Aceita também as props nativas de `<div>`.

## Acessibilidade

- Mesma regra do [Alert](/components/alert/): `error` e `warning` usam `role="alert"`, os demais `role="status"`.
- O Banner não tem borda nem raio: ele ocupa a largura do contêiner. Posicione-o você mesmo no topo da página.

### Quando usar

Manutenção programada, anúncios, avisos globais.

### Quando não usar

Feedback de uma ação específica (use [Alert](/components/alert/) ou Toast).
