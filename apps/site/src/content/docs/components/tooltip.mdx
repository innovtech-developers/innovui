Dica contextual flutuante que aparece no **hover ou foco** de um elemento. Serve para informação **complementar e breve**, nunca crítica: explicar um ícone sem rótulo, mostrar um atalho de teclado.

<TooltipDemo client:load />

```tsx
import { Tooltip, Button } from '@innovui/react'

<Tooltip content="Abre as configurações">
  <Button variant="secondary">Configurações</Button>
</Tooltip>
```

O filho do `Tooltip` é o elemento que dispara a dica: ele precisa aceitar `ref` e foco (um `<button>`, um link, o `Button` ou o `IconButton` da lib).

## Posição, título e seta

<TooltipTitleDemo client:load />

```tsx
<Tooltip side="bottom" content="Abre as configurações">…</Tooltip>

<Tooltip title="Salvar" content="Atalho: Ctrl + S">
  <Button>Salvar</Button>
</Tooltip>

<Tooltip showArrow={false} content="Sem seta">…</Tooltip>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `content` | `ReactNode` | — | **Obrigatória.** O texto principal. |
| `title` | `ReactNode` | — | Título em destaque acima do texto. |
| `side` | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'` | Lado do trigger em que aparece. Se não couber, o Radix inverte sozinho. |
| `showArrow` | `boolean` | `true` | Mostra a seta apontando para o trigger. |
| `delayDuration` | `number` | `200` | Atraso para abrir, em ms. |
| `open` / `defaultOpen` / `onOpenChange` | — | — | Controle do estado de abertura. |
| `className` | `string` | — | Mesclado com as classes internas via `tailwind-merge`. |

## Acessibilidade

- O trigger recebe `aria-describedby` apontando para o tooltip (`role="tooltip"`); abre também com **foco do teclado**, não só com o mouse.
- `Esc` fecha o tooltip.
- O conteúdo tem no máximo 240px de largura e quebra em várias linhas.
- Um tooltip **não é interativo**: não coloque links ou botões dentro dele.
- Em telas de toque não há hover; não dependa do tooltip para informação necessária.

### Quando usar

Explicar ícones sem rótulo, atalhos de teclado, informação complementar breve, rótulos truncados.

### Quando não usar

Informação crítica ou obrigatória, conteúdo longo ou complexo, elementos interativos dentro da dica e interfaces móveis.
