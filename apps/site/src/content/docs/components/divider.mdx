Separa blocos de conteúdo com uma linha fina: na horizontal, entre seções; na vertical, entre itens lado a lado.

<DividerDemo client:load />

```tsx
import { Divider } from '@innovui/react'

<Divider />
<div className="iu:flex iu:h-6 iu:items-center iu:gap-3">
  Perfil <Divider orientation="vertical" /> Segurança
</div>
```

## Props

| Prop | Tipo | Padrão | Descrição |
|---|---|---|---|
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` | O vertical se estica pela altura do pai flex (`align-self: stretch`). |
| `className` | `string` | — | Mesclado via `tailwind-merge`. |

Aceita também as props nativas de `<hr>`.

## Acessibilidade

Renderiza um `<hr>` (papel `separator`) com `aria-orientation`. Leitores de tela anunciam a separação, então use só onde ela tem significado; para espaço puramente visual, prefira margem.
