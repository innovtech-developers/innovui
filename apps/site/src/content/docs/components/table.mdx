Tabela para dados com várias colunas comparáveis. Usa os elementos nativos de tabela, então leitores de tela navegam por linha e coluna. Em telas estreitas, rola na horizontal em vez de estourar o layout.

<TableDemo client:load />

```tsx
import {
  Table, TableCaption, TableHeader, TableBody, TableRow, TableHead, TableCell,
} from '@innovui/react'

<Table>
  <TableCaption>Pedidos recentes</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>Pedido</TableHead>
      <TableHead>Valor</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>#1042</TableCell>
      <TableCell>R$ 120,00</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## Partes

| Componente | Elemento | Observação |
|---|---|---|
| `Table` | `<table>` | Vem dentro de um contêiner com rolagem horizontal. |
| `TableCaption` | `<caption>` | Nome da tabela. |
| `TableHeader` / `TableBody` | `<thead>` / `<tbody>` | Só as linhas do corpo destacam no hover. |
| `TableRow` | `<tr>` | Linha com borda inferior. |
| `TableHead` | `<th>` | `scope="col"` por padrão; passe `scope="row"` para cabeçalho de linha. |
| `TableCell` | `<td>` | Padding de 16px × 12px. |

Todas aceitam `className` (mesclado via `tailwind-merge`) e as props nativas do elemento. Para alinhar um número à direita, use `className="iu:text-right"` ou `style`.

## Acessibilidade

- Dê nome à tabela com um `TableCaption` (ou `aria-label`).
- Para colunas ordenáveis, marque o cabeçalho ordenado com `aria-sort="ascending"` ou `"descending"` e faça o texto do cabeçalho um botão. A tabela não ordena sozinha.
- Em tabelas largas, a área rolável pode precisar de `tabIndex={0}` para quem usa só o teclado rolar; o `Table` não adiciona isso sozinho.

### Quando usar

Dados comparáveis em colunas: pedidos, usuários, métricas.

### Quando não usar

Layout de página (use [Grid](/components/grid/)) e listas de itens com um só texto principal ([List](/components/list/)).
