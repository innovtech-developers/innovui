# Política de Segurança

## Versões suportadas

Enquanto o projeto estiver na v0.x, apenas a última versão publicada no npm recebe correções de segurança. A partir da v1.0.0, a última major recebe correções; majors anteriores ficam a critério dos mantenedores.

## Reportando uma vulnerabilidade

**Não abra uma issue pública para vulnerabilidades de segurança.**

Envie um e-mail para **security@innovtechsolutions.com.br** com:

- Descrição da vulnerabilidade e impacto potencial
- Passos para reproduzir
- Versão afetada do `@innovui/react`

Você receberá uma confirmação em até 3 dias úteis. Corrigida a vulnerabilidade, publicamos uma nova versão e um aviso no GitHub (Security Advisories) creditando quem reportou, caso deseje.
